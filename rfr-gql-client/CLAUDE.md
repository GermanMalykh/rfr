## Ловушки

- Порт `3001` зашит в redirect URI `rfr-auth` — не менять. Сборка/dev отдельно от Gradle (`npm run dev` и т.д.).
- Новый GraphQL-запрос = новый хук в `src/hooks` с стабильным `operationName` (удобно перехватывать в e2e).
- В `rfr-api` уходит только `access_token`; `id_token` — для logout hint.
- Apollo сразу кладёт ответ мутации в кэш/UI. Успешный snackbar не значит, что данные сохранились — проверяй повторным чтением (фото на бэке всё ещё мок).
- UI-компоненты из MUI; свои «с нуля» не плодить.
