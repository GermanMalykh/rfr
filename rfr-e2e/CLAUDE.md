## Ловушки

- Настройки только через `TestConfig`: `-Drfr.<ключ>`, иначе `RFR_<КЛЮЧ>`, иначе дефолт (список ключей — в README модуля).
- Page Objects — skill `rfr-page-objects`; пакеты и слои — как в README «Архитектура», новые классы только туда.
- В коде модуля без комментариев и Javadoc: смысл в именах и `@Step`.
- Логин в тестах только UI. Токены в localStorage не подставлять.
- Прогон через Playwright MCP — разведка, не доказательство. Зелёный результат — `./gradlew e2e` / `:rfr-e2e:test`.
- Пользователей создаёт и убирает цепочка `@User` → `UserExtension` → `UserFixture`. Без массовых `DELETE`/`TRUNCATE`.
