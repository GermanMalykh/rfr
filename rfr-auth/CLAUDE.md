## Ловушки

- `POST /register` пишет только в `rangiffler-auth`. Профиль в api появится позже, на первом `Query.user`.
- Регистрация с CSRF той же сессии: сначала `GET /register`. Успех — 201, валидация/занятый username — 400. Правила полей — в форме/аннотациях, не дублировать здесь.
- `GET /login` без сохранённого OAuth-запроса сразу редиректит на фронт. Нормальный вход — через `/oauth2/authorize` или Login на фронте.
- RSA-ключ подписи новый при каждом старте → старые JWT после рестарта auth мертвы.
- Авторизации и сессии in-memory — рестарт их обнуляет.
- Клиент `client` публичный (без секрета), refresh token не выдаётся.
